# Recommended answers to open human questions

Owner instruction, 31/10/2026 ([ADR-0098](../decisions/0098-production-on-google-cloud.md)): every open
question in [human-actions.md](human-actions.md), whoever owns it, takes its recommended answer so that
development never waits. Where a default is in force, the recommended answer is to keep it. This file holds
the recommendation for each question that had no stated default, plus H-56. All of them are reviewed at the
testing phase after development, before any real tenant goes live; nothing here is a DCB0129 sign-off, a
DPIA approval or a legal opinion. Questions still on unmerged branches are included, with their branch.

"Build change" marks a recommendation that differs from what is built; those changes are scheduled as
follow-up work and listed in [STATUS.md](STATUS.md).
