# How to read and sign an organisation document

Open one of your organisation's documents, such as a procedure, and sign that you have read it.

**Who can do this**: every member of staff. Family members cannot see these documents.

**Register row**: PLAT-009.

## Steps

1. Go to **Documents** in the menu. **Organisation documents** lists each one with its version,
   when it was stored, its size and how many signatures it has.
2. Choose the document. **About this document** shows its **Version**, when it was **Stored**,
   its **File name**, **Size** and how long it is **Kept for**.
3. Choose **Download PDF** and read it.
4. Under **Sign this document**, type **Your full name** as you would sign it.
5. Tick **I have read this version of the document**.
6. Choose **Sign document**. The page says "Document signed." and your name shows under
   **Signatures**.

## Good to know

- Your signature is tied to that exact version. When a new version is uploaded, it starts with no
  signatures, so you sign again.
- If the page says "This is version" with a number and "A newer version has replaced it.", choose
  **Open version** and the newer number to read the current one.
- **Legal hold** means the document must be kept, whatever its usual retention.
- If the page says "This file has not been checked for viruses yet, so it cannot be opened.", try
  later. Ask Thapsus Care support if it stays like this.
- Documents about a person are on that person's record, not here. Policies that staff read and
  sign are under **Policies** (see [How to read and sign a policy](read-and-sign-a-policy.md)).
