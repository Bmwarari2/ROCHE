# How to write a daily note

**Who can do this**: care workers (for the people assigned to them), senior carers, nurses and
managers.

**Register row**: CARE-009.

## Steps

1. Open the person's record and choose **Notes**.
2. Under **Write a note**, choose **What is it about?**, for example "Eating and drinking".
3. Under **Note**, write what happened in plain words.
4. Under **When did it happen?**, leave **Now**, or choose **Earlier** and enter the date and time.
5. Choose **Save note**. Harbour says "Note saved".

## Correct a note

Notes cannot be deleted. A correction is added and the original stays visible with a line through
it.

1. Find the note and choose **Correct this note**.
2. Change the **Corrected note**.
3. Say why under **Reason for the correction**, for example "Wrong number of carers recorded".
4. Choose **Save correction**.

## Good to know

- A note written more than 2 hours after the event shows **Late entry**. That is fine: write it
  as soon as you can, with the time it happened.
- The list shows the last 3 days. Choose **Show the last 7 days** to see more.
- If you are copying from a paper downtime form, see
  [How to enter paper records after an outage](enter-paper-records-after-an-outage.md).
- Voice-to-text and writing notes with no signal are mobile app features still being built.
