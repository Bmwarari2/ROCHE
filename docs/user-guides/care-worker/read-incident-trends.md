# How to read incident trends

See how many incidents and near misses were recorded in each of the last six months, by type.

**Who can do this**: anyone who can read incidents. You see counts from the incidents you can
see.

**Register row**: SAFE-010.

## Steps

1. Go to **Incidents** in the menu and choose **Incident trends**.
2. Read the table: one row for each **Type**, one column for each month, and a **Total**.
3. Open the incidents themselves, and their investigations, to understand what is behind a count.

## Good to know

- The counts are for the location you have chosen, named at the top of the page.
- **Counts only, as recorded.** Each incident counts in the month it happened, in UK time.
  Thapsus Care does not judge what a count means.
- If the page says "These counts leave out incidents you cannot see", the counts are not the
  whole home's. Ask your manager for the home's figures.
- If a month shows a number with "or more", there were too many to count at once, so the real
  number may be higher.
