# How to read and acknowledge the shift handover

Harbour builds the handover from the record: falls, NEWS2 scores needing a response, incidents,
alerts, body map marks, overdue or missed tasks, refused care and notes for handover.

**Who can do this**: care workers, agency workers, senior carers, nurses and managers. You see
only the items about the people you may see.

**Register rows**: CARE-013, COMMS-006. On the web only for now.

## Read and acknowledge it

1. Go to **Handover** in the menu. Choose your home if Harbour asks.
2. Open the shift under **This shift**. If it says "This shift's handover has not been compiled
   yet", choose **Compile this shift's handover**.
3. Read every item. Use the links (for example **Open Ada's charts**) to check the record.
4. Choose **I have read this handover**. The page shows **You have acknowledged it**.
5. If Harbour says items were added since you opened it, read the items marked **New to you**,
   then choose **I have read this handover** again.

## Add a note

1. Choose **Add a note to the handover**, or the note button beside an item.
2. Write the **Note** and choose **Save note**.

Notes add to the handover. They never change an item.

## Good to know

- Acknowledging means you have read the items shown to you. If something new is added later, you
  will be asked to read it too.
- If nobody on the incoming shift acknowledges it, the nurse in charge is alerted an hour after the
  shift ends: "A handover has not been acknowledged".
- Day shift starts at 08:00 and night shift at 20:00 unless your home has set other times.
- Once the shift ends the handover is locked. Add anything new to the next shift's handover.
- Allergy changes, stopped medicines and resuscitation decisions should still be handed over by
  word of mouth too.
