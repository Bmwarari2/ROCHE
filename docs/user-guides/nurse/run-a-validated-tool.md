# How to run MUST, Waterlow or Braden, or ask the falls questions

**Who can do this**: nurses, senior carers, care workers (for the people assigned to them) and
managers.

**Register rows**: CARE-003, CARE-006.

## Steps

1. Open the person's record and choose **Assessments**.
2. Choose **Run MUST**, **Run Waterlow**, **Run Braden** or **Ask the falls questions**.
3. Answer every question. The tool needs them all.
4. Enter **When was the assessment done?**.
5. Choose **Calculate and save**.

## Read the result

- The score and band, for example "Score 3, High risk".
- **How the result was worked out**: the points for each answer.
- **What this result raised**, for example a task to refer to a dietitian or an alert to the nurse
  in charge.
- **Next due**, the published source, and your organisation's escalation policy.

## Important

- Harbour calculates each tool exactly as published and never changes a score or band.
- **The score supports clinical judgement. It never replaces it.** Follow the published response
  and your escalation policy.
- The falls questions give **no score**: NICE advises against falls prediction scores (NG249).
  Harbour shows the NICE recommendation that applies.
- Waterlow and Braden show only if your organisation has switched them on.
- NEWS2 is recorded under **Charts** (see
  [How to record vital signs](../care-worker/record-vital-signs.md)).
- A result cannot be corrected on the web. Run the tool again: the earlier result shows
  "Corrected by a later result".
