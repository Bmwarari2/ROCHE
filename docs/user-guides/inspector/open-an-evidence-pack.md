# Evidence packs for inspectors

A home can send an inspector a watermarked evidence pack by a link that only the inspector can open,
for a limited time. A one-time code is sent to the inspector's email separately from the link.

**Register row**: QUAL-003.

## What is available now

Composing, releasing and opening a pack works through Harbour's system only. There is no page yet
where an inspector types the code and downloads the pack, and no screen where the home composes
it. Until there is, ask the home to share evidence another way.

When the screens are built this guide will give the steps. What will not change:

- The link works only for the email address it was sent to.
- The code is sent in a separate message from the link. After too many wrong codes the link locks
  for good, and the home must send a new one.
- The pack is watermarked with who it is for. The file is deleted when the link expires or the
  home withdraws it.
