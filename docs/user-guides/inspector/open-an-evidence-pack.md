# How to open an evidence pack

A care provider can send you a watermarked evidence pack by a link that only you can open, for a
limited time. A one-time code is sent to your email separately from the link.

**Who can do this**: the inspector or commissioner the provider sent the link to. You do not need a
Thapsus Care account.

**Register row**: QUAL-003.

## Steps

1. Open the link from the provider's email, all of it. The page says **Open the evidence pack**.
2. Choose **Email me a code**. The page says "Code sent. Check your email."
3. Under **Enter the code from your email**, type the **Six-digit code**, for example 123456. It
   works for a few minutes, once.
4. Choose **Open the pack**. The page says **Your evidence pack is ready**.
5. Choose **Download the pack**. You can download it again while the link works.
6. When you have it, choose **Finish and remove access from this browser**, especially on a shared
   computer.

## Good to know

- The link works only for the email address it was sent to. If the code did not arrive, choose
  **Email me a new code**.
- After too many codes that did not match, the link locks for good. Ask the provider for a new
  link.
- Every page shows who the pack was prepared for and why. Keep it secure and do not share it
  further.
- The pack is deleted when the link expires or the provider withdraws it. The page then says "This
  link has expired" or "This pack has been withdrawn".
- If the page says "This link is not complete", open the whole link from the email again.
