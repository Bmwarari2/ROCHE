# How to write and approve a pay rule set

Set your organisation's own hourly rates and allowances, from a date, so pay runs can be
calculated.

**Who can do this**: people who run pay for the whole organisation (owner, Finance). One person
writes the draft; someone else approves it. You need to have signed in with your passkey or
authenticator app.

**Register row**: SCHED-005.

## Steps

1. Go to **Pay** in the menu and choose **Pay rule sets**.
2. Under **Draft a rule set**, enter the **Rule set name** and the **In force from** date.
3. Under **Hourly rates by role**, write one line for each role: the role, an equals sign, then the
   hourly rate in pounds, for example `carer = 12.50`.
4. Enter the **Sleep-in flat rate, in pounds** and the **Mileage rate, in pounds per mile**, or
   leave them blank for none.
5. Choose **Save draft rule set**. It shows **Draft, waiting for approval**.
6. Someone else who approves pay opens **Pay rule sets** and chooses **Approve rule set**. It then
   shows **Approved** and **In force from** its date.

## Important

- Statutory figures such as the minimum wage are not set here: they come from the rate table. A
  rate below the minimum wage is caught when a pay run is calculated.
- Whoever wrote or last changed a draft cannot approve it. An approved rule set is fixed; a change
  is a new version.
- A pay run uses the approved rule set in force on the first day of its period. A run cannot start
  without one.
- Pay is organisation-wide. A manager whose access is limited to some homes does not see pay.
