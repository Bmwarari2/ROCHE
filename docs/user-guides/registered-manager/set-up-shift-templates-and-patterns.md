# How to set up shift templates and patterns

Describe the shifts a home works, and the patterns that repeat them, so you can fill a rota
quickly.

**Who can do this**: people who build rotas (Registered Manager, deputy manager, care coordinator,
owner).

**Register row**: SCHED-002.

## Steps

1. Go to **Rota** in the menu and choose the home, then choose **Shift templates and patterns**.
2. Under **Make a shift template**, enter:
   - **Name**, for example Early, Late or Waking night;
   - **Kind of shift**, for example Work, Sleep-in or On call from home;
   - **Starts** and **Ends** as 24-hour times, for example 07:30. An end at or before the start is
     the next day;
   - **Break in minutes**, up to 240.
3. Tick **Counts as care on the floor** if the shift is hands-on care, and **Needs supervision**
   if whoever works it must be supervised. Choose **Make template**.
4. To repeat shifts, go to **Make a shift pattern**. Enter a **Name**, choose the **Cycle** and,
   under **Shifts on each day**, enter how many of each shift run on each day of the cycle. Leave 0
   for none. Choose **Make pattern**.
5. To stop using a template or pattern, choose the archive button that names it, for example
   "Archive Early", then **Archive template** or **Archive pattern**.

## Good to know

- Only shifts that count as care add to the care hours in the rota check. A supervised shift does
  not count unless you tick **Counts as care on the floor**.
- Archiving stops a template or pattern being used for new shifts. Shifts already on a rota stay
  as they are.
- Day 1 of a pattern is the first day it is added from, so the next rota carries on the cycle.
