# How to read the statutory notification clocks

Each statutory notification has a clock that starts when the incident happened.

**Who can see this**: people who manage incidents. Go to **Incidents**, then
**Statutory notifications**. Each incident page also shows its own notifications.

**Register rows**: SAFE-002, SAFE-003, SAFE-004, SAFE-005.

## The list

- **Still to do** comes first: unknown clocks, then overdue, then the soonest due.
- **Submitted or not required** comes after.
- The clocks do not move while the page is open. The page says when they were worked out. Reload
  it to bring them up to date.
- People you cannot see are shown by number, for example "person 2". The same number is the same
  person.

## What the words mean

| You see | It means |
| --- | --- |
| Overdue for 3 hours | The deadline has passed and it is not done. Do it now. |
| Due | The deadline has not passed yet. |
| Submitted | Recorded as sent to the regulator. |
| Not required | A submitter recorded why the law does not need it. |
| Clock not known | Harbour could not work out the deadline. Treat it as urgent. |
| Draft / Ready to submit | How far it has been prepared. |
| Without delay: the clock started ... | The law says "without delay", so it is overdue from the start. |
| This time is Harbour's target, not a legal deadline | Harbour's own target. For a safeguarding concern or a missing person, act as soon as possible all the same. |
| Provisional | It rests on a "Not sure yet" answer. Submit it, or record that it is not required. If in doubt, notify. |
| The answers no longer show this is needed | A submitter must still decide. Harbour never closes it by itself. |
| Notifications not checked yet | Harbour has not checked this incident. Check what the law needs yourself; if you manage incidents but do not submit notifications, tell the Registered Manager too. |
| No notification found | Harbour found nothing to notify on what is recorded so far. It only says this when nothing is open or waiting. |

## Overdue alerts

When a notification goes overdue, the Registered Manager and owner get an urgent alert in
**Notifications**: "A statutory notification is overdue". If nobody deals with it, it goes to the
Nominated Individual.

**Acknowledging the alert does not submit the notification.** It stops the reminders. Open the
notification and record it as submitted or not required.

## Good to know

- Harbour supports the Registered Manager's judgement and never replaces it.
- Kinds include the Care Quality Commission (deaths, serious injuries, abuse, police incidents,
  events that stop the service running safely, DoLS outcomes), RIDDOR to the Health and Safety
  Executive, safeguarding to the local authority, duty of candour, LeDeR, outbreaks to UKHSA, the
  medical examiner and missing persons to the police.
