# How to approve timesheets

Check the time staff clocked at your home and approve each entry so it can be paid.

**Who can do this**: people who approve rotas and timesheets (Registered Manager, deputy manager,
owner). A care coordinator can see the timesheets but not approve them.

**Register rows**: SCHED-004, SCHED-003.

## Steps

1. Choose the home, then go to **Timesheets** in the menu. Entries from the last 14 days are
   listed, those waiting for approval first.
2. For each entry, check the member of staff, the times, what kind of time it was and how long
   they worked. Any problem with the clock times is said in words, for example "A break was started
   and never ended."
3. If the entry is right, choose **Approve timesheet entry**. It shows **Approved**, and the working
   time check runs.
4. To see the working time check for that person, choose **Working time for** and their name. See
   [how to read working time results](read-working-time-results.md).

## Important

- You cannot approve your own entry, one you entered or corrected, or one you last changed.
  Someone else must.
- An entry can only be approved once it has ended. An approved entry never changes: a correction
  is a new entry, and the original is shown struck through as **Corrected** and no longer counts.
- The working time check is advice. It never stops an approval. A breach raises a task for the
  Registered Manager.
- Only approved entries are paid. A draft left in a pay period stops that pay run being locked.
